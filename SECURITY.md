# Security Policy

## Reporting a Vulnerability

Do not open a public issue, pull request, or discussion for a security problem.

Report it in private through GitHub: open the repository's **Security** tab and select
**Report a vulnerability**. Only the maintainers see the report.

Include:

- The Voidwall commit or image you tested.
- The configuration that is needed to reproduce the problem.
- The steps to reproduce it, and what you expected to happen.

Do not put real personal data or real credentials in the report. Use placeholder values.

## Supported Versions

Voidwall has no stable release yet. Fixes go to the `main` branch only.
